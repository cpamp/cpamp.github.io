Home Assistant Personal Control

Home Assistant Personal Control is a private application used to connect my personal Home Assistant installation with Google services.

The application allows my Home Assistant automations to send commands to Google Assistant in order to control smart-home devices associated with my Google account.

This application is intended solely for personal use and is not offered as a public or commercial service.

Data Use

The application accesses Google services only as necessary to authenticate my Google account and perform smart-home commands that I initiate through Home Assistant.
